01 · The diagnosis

Why it looks off today

It isn't one bad page — the app is wearing three disconnected visual languages at once, and the customer-facing pages still carry the old coffee-shop skin. Grounded in the actual code:

☕ The loyalty hub still wears the old café palette worst offender

The screens customers actually see (FidelityHub, wheel, store) hardcode warm brown-black text #1A1410 on beige lines #EFEAE3 — leftovers from Scaniha's menu product — with purple just bolted on top. It reads muddy and unbranded.

🔤 Arabic fonts on a French product high impact

The landing's primary typeface is Tajawal / Cairo — Arabic-optimised fonts — used for French copy. The intended Poppins + Inter were never wired, so everything falls back to a generic, slightly-wrong look.

🎨 No design system — 91 ad-hoc colors

91 distinct hardcoded hex values across the client + landing code. Landing, client, and admin each invented their own palette and spacing. Nothing shares tokens, so nothing looks like one product.

🌀 Dated, noisy motion

The landing leans on drifting blur "orbs", shimmer sweeps, a logo marquee and floating images — 2021-era effects that add noise, not delight, and hurt performance (no next/font, render-blocking font imports).

02 · The new direction

One system: playful, vibrant, rewarding

Purple stays the anchor (your brand), but we give it a scale, cool neutrals, and a gold reward accent — the color of points, coins and wins. Coral adds energy for streaks. Big rounded shapes, colored soft shadows, springy motion.

06 · Surface by surface

What changes on each screen

1

Customer loyalty hub & onboarding

Highest value · seen by every customer
  • Rip out the warm-brown palette; rebuild FidelityHub (Ma carte / Jeux / Boutique) on the new tokens
  • Gold points balance with count-up animation; level card, streak flame, achievements as playful stickers
  • Value-first auth screen redesigned; the "bientôt disponible" state made friendly, not dead
  • Reward store cards with gold price tags + real redeem celebration
2

The games

The reason people come back
  • Roulette wheel: crisper segments, gold rim, motion-blur spin, satisfying tick + ease-out landing
  • Slot 777: chunkier reels, gold wins, near-miss anticipation
  • Win moment: full-screen confetti + gold burst + prize card — make winning feel like winning
  • Consistent "one tap = one delight" feedback (spring, haptic-style scale, sound-ready)
3

Landing page

First impression for café owners
  • Kill Arabic fonts → Poppins/Inter; drop orb-soup, marquee, floating images
  • Rebuild hero around a real product shot of the new hub + a single confident CTA
  • Purposeful scroll motion (spring reveals, count-ups), gold-accented "rewards" storytelling
  • Clear owner value sections, honest social proof, refined pricing cards
4

Admin & super-admin

Already cleanest · needs alignment
  • Re-point the v2 kit tokens to the new shared scale (one source of truth)
  • Warmer, more playful data cards; gold for revenue/points KPIs; better empty states
  • Tighten the dark sidebar + floating nav; consistent chips, toasts, dialogs

08 · Guardrails

So it stays great

🎯
Token discipline

Every color/space/radius from the token set. Lint rule to reject raw hex in components — no more 91-color drift.

♿
Accessibility (AA)

Contrast-checked pairs, focus rings, reduced-motion honored, 44px tap targets. Playful ≠ inaccessible.

⚡
Performance

next/font self-hosting, no render-blocking imports, motion via transform/opacity only. Fast on café Wi-Fi.

🧩
One kit, every surface

Landing, client, admin all import the same Button/Card/Chip/Field. Fix once, fixed everywhere.
